# AI Lead Automation

An educational resource hub about affiliate traffic, consent-based lead generation, and practical SEO. No earnings guarantees.

The site is maintained as static HTML for straightforward deployment. Technical SEO needs the final hosting domain before canonical URLs and an absolute XML sitemap can be configured.

Public educational pages are intended to help readers; the link archive is an unverified reference inventory and is not indexed. The project contains no tracking scripts or forced redirects.


AI-assisted search content: see [SEO_SETUP.md](SEO_SETUP.md), [EDITORIAL_CALENDAR.md](EDITORIAL_CALENDAR.md) and [privacy.html](privacy.html).


Production-domain SEO: `https://masteraffiliate.wasmer.app/` was supplied by the owner, with committed canonical URLs, sitemap.xml and robots.txt. This documents intended hosting, **not** verification of Wasmer deployment. After publishing future guides, run `python3 tools/finalize_seo.py https://masteraffiliate.wasmer.app` to refresh the sitemap and canonical tags.
