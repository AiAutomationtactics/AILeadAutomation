# AI Lead Automation

An educational resource hub about affiliate traffic, consent-based lead generation, and practical SEO. No earnings guarantees.

The site is maintained as static HTML for straightforward deployment. Technical SEO needs the final hosting domain before canonical URLs and an absolute XML sitemap can be configured.

Public educational pages are intended to help readers; the link archive is an unverified reference inventory and is not indexed. The project contains no tracking scripts or forced redirects.
